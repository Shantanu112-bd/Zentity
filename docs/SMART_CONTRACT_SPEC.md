## 1. Contracts Overview
1. **`PramaanVerifier.sol`**: Generated Groth16 pairing verifier contract (generated by snarkjs from compiled Circom circuit). Verifies proof validity given public inputs.
2. **`PramaanRegistry.sol`**: Manages verification state, registered issuer keys, and nullifier records.

## 2. PramaanRegistry Interface

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IPramaanRegistry {
    event Verified(
        bytes32 indexed nullifier,
        bytes32 indexed scopeId,
        address indexed recipient,
        uint256 actionNonce
    );

    event IssuerKeyUpdated(bytes32 indexed keyHash, bool active);
    event PausedStateChanged(bool isPaused);

    function registerVerification(
        uint256[2] calldata a,
        uint256[2][2] calldata b,
        uint256[2] calldata c,
        uint256[8] calldata publicInputs
    ) external returns (bool);

    function isNullifierSpent(bytes32 scopeId, bytes32 nullifier) external view returns (bool);
    function isIssuerKeyValid(bytes32 keyHash) external view returns (bool);
}
```

## 3. Invariants & Security Rules
- **Nullifier Isolation:** Nullifier mappings are partitioned strictly by `scopeId`.
- **Replay Protection:** A nullifier cannot be submitted more than once within the same `scopeId`.
- **Recipient Assertion:** Transaction calldata recipient must match `publicInputs[recipient]`.
- **Chain ID Assertion:** Contract enforces `block.chainid == publicInputs[chainId]`.
- **Deadline Check:** Revert if `block.timestamp > publicInputs[deadline]`.
- **Pause Capability:** Emergency admin pause stops all new registrations immediately.
